# 文件与目录

这一章的目标：让你在任何目录里都能**知道自己在哪、找到想要的文件、安全地复制和移动**。

> 所有命令都先在 `~/linux-练习场` 里试，不要在桌面、下载目录或系统目录里练手。

## 一、先知道自己在哪、周围有什么

```bash
pwd          # 打印当前目录的绝对路径
ls           # 列出当前目录内容
ls -l        # 详细列表：权限、大小、修改时间
ls -lh       # 同上，文件大小换算成 K / M / G
ls -la       # 含隐藏文件（以 . 开头的文件，如 .bashrc）
ls -S        # 按文件大小从大到小排
ls -t        # 按修改时间从新到旧排
```

`-l`、`-h`、`-a` 可以叠写：`ls -lah` 和 `ls -l -a -h` 效果一样，前者更常用。

## 二、在目录之间移动

```bash
cd 文档              # 进入当前目录下的「文档」
cd /home/user/文档   # 用绝对路径进入
cd ..                # 回到上一级
cd ~                 # 回到家目录
cd -                 # 回到上一次所在的目录（来回跳很方便）
```

## 三、创建与删除

```bash
mkdir 我的笔记        # 创建一个目录
mkdir -p a/b/c       # 递归创建：父目录不存在就一起建
touch 新文件.txt      # 创建空文件；文件已存在则只更新修改时间
rm 文件.txt           # 删除文件
rm -r 目录名          # 递归删除目录及其内容
rm -rf 目录名         # -f 强制，不逐条询问
```

> **`rm -rf` 是不可逆的**，没有回收站。执行前先 `pwd` 确认路径，宁可多确认一次。

`rmdir` 只能删**空目录**，有内容时会报错。实际用 `rm -r` 更多。

## 四、复制与移动

```bash
cp 源 目标             # 复制文件
cp -r 源目录 目标目录   # 复制目录必须加 -r
cp 源 目标/            # 目标结尾带 /，表示复制到该目录内
mv 源 目标             # 移动；在同一目录下就是改名
```

一个小区别：`cp` 后原文件还在，`mv` 后原文件不在了。

## 五、找东西

```bash
which python3    # 这个命令到底执行的是哪个程序（看 PATH）
find . -name "*.txt"        # 在当前目录及子目录里找所有 .txt
find ~ -type f -size +10M   # 在家目录里找大于 10M 的文件
```

`find` 很强大也很容易写错目标，先跑一遍不带动作的版本确认范围。
