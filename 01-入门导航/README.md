# 入门导航

## 终端是什么

终端（Terminal）是一个**用文字而不是鼠标和你聊天的窗口**。你敲命令，系统执行，再把结果用文字返回给你。

- Linux：装系统时自带，常见名字是「终端」「Konsole」「GNOME 终端」
- macOS：在「应用程序 → 实用工具」里找「终端」，或按 `Command + 空格` 搜 `Terminal`
- Windows 用户：可以装 WSL，或用 Git Bash；纯 `cmd` 的语法差异较大，本文示例以 Linux / macOS 为准

## 怎么读一条命令

```
ls -l -h /home
↑  ↑   ↑  ↑
命令 参数 参数 目标
```

- `ls` 是要做的事：列出目录内容
- `-l` `-h` 是参数，用来调整行为；有的命令用 `--long` 这种长写法
- `/home` 是目标：对谁做这件事

记住这一层，遇到没见过的命令也不慌——先想「它在做什么」，再看参数。

## 提示符里的 `~` 和 `$`

打开终端后，你会看到一行类似这样的文字：

```
user@computer ~ $
```

- `user@computer`：当前用户和机器名
- `~`：你当前所在的目录（`~` 是「家目录」的简写，等价于 `/home/你的用户名`）
- `$`：后面就是你可以输入命令的地方

## 前 3 条命令，先保命

| 命令 | 作用 | 备注 |
|---|---|---|
| `pwd` | 我在哪 | 迷路时第一反应，打印当前目录的绝对路径 |
| `ls` | 这里有什么 | 列出当前目录的内容 |
| `cd [目录]` | 去别的地方 | `cd ..` 回到上一级，`cd ~` 回到家目录 |

## 三条保命规矩

1. **先 `pwd` 再 `rm`**：删东西之前，先确认自己在哪个目录。
2. **不确定的命令先空跑一遍**：很多命令支持 `--dry-run` 或 `-n`，先看看会发生什么。
3. **`sudo` 不是万能钥匙**：它会以超级管理员身份执行，输完回车就没法撤回，确认命令对再按。
