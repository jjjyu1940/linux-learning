# 查看与编辑

这一章的目标：学会**看文件内容、在里面搜关键字、把输出存成文件**。

## 一、查看文件

```bash
cat 文件.txt        # 一次性输出全部内容
less 文件.txt       # 分页看，空格翻页，按 q 退出
head -n 20 文件.txt # 只看前 20 行
tail -n 20 文件.txt # 只看后 20 行
tail -f 日志.log    # 实时跟随新增内容（看日志很常用）
```

- 文件很短 → `cat`
- 文件很长 → `less`，它不会把屏幕刷满
- 只想看开头或结尾 → `head` / `tail`

## 二、在内容里搜

```bash
grep "错误" 日志.log            # 找含「错误」的行
grep -i "error" 日志.log        # -i 忽略大小写
grep -rn "函数名" src/           # -r 递归目录，-n 显示行号
grep -C 3 "错误" 日志.log        # 命中行前后各 3 行也一起显示
```

`grep` 是「找信息」的主力，配合后面的管道效果更强。

## 三、管道：把左边的输出交给右边

```bash
ls -l | head -n 5          # 列出内容，只取前 5 行
ps aux | grep python        # 在所有进程里找 python
cat 日志.log | grep "错误" | wc -l   # 数一数「错误」出现了几次
```

`|` 读作「管道」，作用是：把左边命令的标准输出，接到右边命令的标准输入。

## 四、重定向：把输出存进文件

```bash
echo "hello" > 文件.txt     # > 覆盖写入
echo "world" >> 文件.txt    # >> 追加写入
ls -l > 清单.txt            # 把 ls 的结果存成文件
```

> `>` 会直接覆盖原文件，且没有提示。想保留原内容时用 `>>`。

## 五、编辑器

```bash
vi 文件.txt      # 或 vim
nano 文件.txt    # 对新手更友好，底部有快捷键提示
```

不会用 vi 也完全没问题，先用 `nano` 或你自己顺手的编辑器。`vi` 最基础的三个动作：

1. 打开后是「命令模式」，按 `i` 进入编辑模式
2. 编辑完按 `Esc` 回到命令模式
3. 输入 `:wq` 回车保存并退出；`q!` 是不保存强制退出

## 六、往文件里写内容

```bash
echo "这行会写进文件" >> 笔记.txt
cat > 新文件.txt            # 回车后逐行输入，结束按 Ctrl + D
```
