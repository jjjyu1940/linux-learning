# Linux / Unix 常用命令速记

一份给终端新手看的命令备忘笔记。不追求命令大全，目标是让你**打开终端敢动手**。

- 适用：Linux 与 macOS 终端
- 形式：按场景拆成小章节，每条命令配「这条命令在做什么」和一段可照抄的示例
- 许可：[MIT](LICENSE)

> 约定：`[]` 内为占位参数，使用时替换为实际内容，**不要连同 `[]` 一起输入**。

## 快速开始

1. 选一个**不会被你存重要文件**的目录，当作练习场：`mkdir ~/linux-练习场 && cd ~/linux-练习场`
2. 从 [01-入门导航](01-入门导航/README.md) 开始读，每读完一小节就动手敲一遍
3. 做完 [07-实战练习](07-实战练习/README.md) 的 6 个练习，你就走完了「查看—复制—对比—过滤—提权执行」的完整链路
4. 遇到报错先别删文件，看 [04-权限与用户/常见报错.md](04-权限与用户/常见报错.md)
5. 我们还有gitee仓库https://gitee.com/mcplayer1553880/linux-learning
## 提醒

- 示例中的 `#` 开头是注释，`$` 开头是要你自己敲的命令；实际输入时不要带上这两个符号
- 涉及 `rm -rf`、`dd`、`chmod`、`chown` 的操作，务必先确认路径再回车
- `dd` 威力大，使用时再三核对 `of=` 目标路径
- 不确定某个命令怎么用，先试 `命令 --help` 或 `man 命令`
