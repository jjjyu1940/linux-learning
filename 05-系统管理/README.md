# 系统管理

这一章的目标：知道**机器现在忙不忙、哪个进程在占资源、怎么安全地结束一个卡住的进程**。

> 系统管理命令涉及进程和权限，误操作可能影响正在跑的程序。以下示例以查看和温和结束进程为主。

## 一、看资源占用

```bash
top                  # 实时刷新，按 q 退出
top -bn1 | head -n 15   # 非交互模式跑一次，方便抓前几行
htop                  # 更直观的版本，需安装
free -h               # 内存使用情况（人类可读）
df -h                 # 磁盘空间（人类可读）
du -sh *              # 当前目录下每个条目各占多大
```

`top` 首屏信息怎么读：

- 第一行：开机时长、登录用户数、平均负载
- 第二行：任务总数、运行中、睡眠、停止、僵尸
- 第三、四行：CPU 使用分布、内存与交换分区
- 下面的表格：每个进程的 PID、CPU%、MEM%、命令

## 二、看进程

```bash
ps                   # 当前 shell 的进程快照
ps aux               # 系统上所有进程的快照
ps aux | grep python # 只看 python 相关
```

`ps` 只拍一张快照，不会自动刷新；要实时看用 `top`。

## 三、结束进程

```bash
kill 1234            # 温和地请 PID 为 1234 的进程退出
kill -9 1234         # 强制结束（最后手段，可能留下未保存的数据）
```

顺序建议：先 `kill PID`，等几秒；不响应再 `kill -9 PID`。

找 PID 的更快方式：

```bash
pkill -f 程序名       # 按名字结束进程
killall 程序名        # 结束所有同名进程
```

## 四、系统信息

```bash
uname -a             # 内核与系统版本
uptime               # 开机时长与平均负载
whoami               # 当前用户是谁
id                   # 当前用户的 uid、gid 与所属组
```

## 五、重启与关机

```bash
reboot               # 重启
poweroff             # 关机
shutdown -h +10      # 10 分钟后关机
```

> 远程连着服务器时，`reboot` 和 `poweroff` 会直接中断你的会话，谨慎使用。
